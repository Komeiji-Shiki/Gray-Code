# 性能优化与架构设计

[返回目录](Home.md)

为了在长对话、超大代码仓库以及高频工具调用场景下依然保持轻快流畅，GrayCode 在架构层面进行了多维度的性能优化。

---

## 1. 核心性能优化维度

### 1.1 文件树与界面虚拟化渲染
- **问题**：大型代码仓库动辄包含数万个文件与深层目录，全量 DOM 渲染会导致界面卡顿、内存暴涨。
- **方案**：左侧文件树与长消息列表限制挂载的节点数量。聊天窗口最多渲染 200 行，本地已加载的历史按 40 行逐步展开；已加载分页用尽后再读取下一页，定位后的双向阅读保持重叠锚点。耗时仍受单条消息内容、设备和浏览器影响。

### 1.2 增量历史游标同步
- **问题**：长会话包含数千条消息与多模态图片，若每次交互都全量读取和解析整个对话历史，会导致严重的 CPU 与 IPC 瓶颈。
- **方案**：采用增量版本游标（Incremental History Cursor）。在会话未发生分支分叉时，仅同步最新追加的消息增量，读取延迟降至毫秒级。

### 1.3 请求快照内容寻址去重（CAS）
- **问题**：多轮工具调用或长上下文对话中，重复的系统提示词、工具声明与历史图片会大量占用磁盘空间。
- **方案**：底层存储对消息快照和多模态附件采用不可变哈希去重，相同内容复用存储。节省比例取决于历史中重复内容的占比；测量时需要同时统计 SQLite 与外部内容文件。

### 1.4 按需依赖加载（Lazy Loading）
- **问题**：全量加载语法高亮器、KaTeX 公式渲染引擎及庞大工具库会显著拖慢工作台启动速度。
- **方案**：采用按需动态导入。只有当消息中实际出现代码块或数学公式时，才动态加载对应的解析库，显著降低首次加载的 JavaScript 体积与启动耗时。

---

## 2. 检索与向量索引设计

- **分层过滤与精确排序**：向量检索与关键词混合检索采用多线程并行处理，在保证排序精度的同时不阻塞主界面的渲染与读写。
- **智能缓存**：记忆向量化与文本嵌入在计算过程中自动复用已计算缓存，避免重复文本多次请求嵌入模型产生额外费用。

## 3. 性能验证

2026-09-26 的搜索修复保留 8 个文件的并发预取，消费完一个文件后立即解除对其全文的引用。此前完成的 Promise 一直保留在数组中，扫描过的全文会累计到搜索结束。

同机 Node.js 22.18.0、Windows x64 合成对照：256 个文件，每个 128 KiB，使用不能走全文快速拒绝的零命中正则 `/(?<!x)needle/gm`，每 32 个文件让出事件循环、执行 GC 并采样堆内存。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 采样峰值堆内存 | 42.34 MiB | 5.40 MiB |
| 相对启动基线增加的堆内存 | 38.35 MiB | 1.41 MiB |
| 匹配数 / 跳过文件数 | 0 / 0 | 0 / 0 |

这些数据反映该工作负载的保留对象，未包含 Electron、原生内存或真实磁盘延迟。结果顺序、输出预算、文件排除及提前结束后的读取回收由搜索回归测试覆盖。

运行记录合并在同一 Node.js 版本下使用 5,000 条历史事件，再依次追加 1,000 条事件。5 次合成测量的中位数从 312.245 ms 降至 0.093 ms；单次追加读取历史 `sequence` 的次数从 14,999 次降至 1 次。该数据只衡量有序追加函数，不包含 Vue 渲染和 IPC，不等同于界面帧率。

同日追加检查发现，旧记忆扫描每页固定申请 16 MiB 缓冲区，到达 EOF 还会再次申请。改为按当前文件大小分配、逐页复用后，4 条记忆连续读取 50 次的本机一次合成对照中，累计 `Buffer.alloc` 申请量由 1,600.13 MiB 降至 0.91 MiB，耗时由 193.46 ms 降至 20.13 ms，结果一致。这是累计申请量，不是峰值内存；耗时来自一次对照，不能视为所有资料库的速度保证。

存储基准使用 `npm run benchmark:platform`：生成 10,000 条合成消息、重复附件和 100 个分支，输出预热分页耗时、校验结果、存储大小及测量限制。NDJSON 对照用于比较序列化体积，不代表旧适配器运行耗时。

界面组件回归用于验证请求次数、渲染窗口和异步竞态；实际桌面交互另用隔离数据目录与本地合成模型验收。外部模型、Bot 和真实用户数据的效果需要独立验证，不能从本地夹具推定。

2026-09-26 的实际桌面验收使用 Electron 44.2.0 / Node 24.20.0，覆盖发送、模型工具循环、提问与拒绝确认、重生成与分支切换、设置草稿保存、HTML预览和图片组切换。1,250 条合成历史从中段连续滚动至真实尾部，消息节点始终不超过 200，连续定位保留最新目标，验收未记录到前端错误。`scripts/smoke-desktop.cjs` 将应用配置、旧设置迁移来源和文档工作区同时隔离到临时目录。

追加修复后再次构建并执行同一实际桌面流程。输入框实测行高 19.5px，两行正文连同 16px 内边距和 2px 边框完整显示在 57px 高度内，四行输入展开到 96px。后端 3,374 项串行句柄追踪通过并正常退出，未报告未关闭句柄。
