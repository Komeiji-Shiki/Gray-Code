# 记忆、桌宠与屏幕感知配置

[返回目录](Home.md)

GrayCode 内置了双层记忆架构（长期事实记忆 + 工程日志记忆）、Live2D 桌面伴侣交互以及屏幕感知能力，为开发者提供更具温度与连续性的开发体验。

---

## 1. 双层记忆体系

为了平衡“项目工程约束”与“跨会话长期认知”，系统设计了两种不同侧重的记忆机制：

### 长期事实记忆（Long-Term Memory）
- **适用场景**：记录关于个人偏好、架构习惯、业务背景知识、跨项目技术选型等。
- **作用域隔离**：划分为“全局个人”、“项目专用”与“角色设定”三种范围，互不串扰。
- **结构化管理**：支持主题层级树、来源追溯、置信度标记以及精确局部修订（精准修改某个属性而无需整段重写）。
- **向量与混合检索**：在对话时自动召回相关事实，输入模型作为记忆上下文。

### 工程日志记忆（Workspace Working Memory）
- **适用场景**：记录当前代码仓库的架构约定、重要演进节点、已知限制与关键待办。
- **工具支持**：模型通过 `memory_wake` 在会话开始时快速感知工程约定，通过 `memory_note` 沉淀未来会话有价值的关键决策。
- **二叉树摘要合并**：历史工程记忆会自动在后台进行两两摘要合并，在保留核心结论的同时防止上下文无限膨胀。

## 2. 桌宠与 Live2D 伴侣配置

在 **设置 → 外观 → 桌面伴侣** 中可以启用并配置你的桌面桌宠：

- **模型导入**：支持导入标准的 Live2D Cubism 模型资源目录（包含 `.model3.json`、贴图及动作定义文件）。
- **参数与表现调节**：
  - **缩放比例**：自定义桌宠在屏幕上的大小。
  - **视线与朝向**：调节模型视线关注方向。
  - **动画与状态映射**：将模型的内置动作分别映射到 AI 的不同状态（如“思考中”、“编写代码中”、“代码审查中”、“遇到错误”等）。
- **轻量节能模式**：在低电量或低配设备上可开启静止或低帧率模式，降低 GPU 占用。

### Clawd 独立桌宠联动

GrayCode 可以向同一电脑上运行的 [Clawd-on-Desk](https://github.com/rullerzhou-afk/clawd-on-desk) 发送任务状态。使用支持 [Custom HTTP Agent](https://github.com/rullerzhou-afk/clawd-on-desk/blob/main/docs/guides/custom-agent-http.md) 的 Clawd 版本。

1. 启动 Clawd，在 **Settings → Agents** 添加 GrayCode 的可执行文件或安装目录，扫描后注册应用，复制生成的 **Agent ID**。
2. 打开 GrayCode 的 **设置 → 外观 → Clawd 独立桌宠联动**，填写 Agent ID、启用联动，再点击 **保存全部**。
3. 点击 **检查连接**。收到确认后，在 GrayCode 开始任务，Clawd 就会显示对话名称，以及思考、工具执行、等待确认、完成或失败状态。对话自动命名或手动重命名后，桌宠中的名称也会更新。取消任务会结束相应状态，不显示完成庆祝。

不同对话使用独立的会话标识，同一对话的连续任务更新同一个会话。名称取自 GrayCode 已保存的对话标题，通过 Clawd 的 `session_title` 字段上报；没有标题时沿用 Clawd 的工作区名称显示。仅发送状态、会话标识、对话标题、工作区路径和工具名称等元数据，不发送消息正文、工具参数或凭据。工具审批和问题回答仍在 GrayCode 中处理。连接检查确认 Clawd 接收了状态；勿扰模式可能抑制可见动画。

联动通过本机 `~/.clawd/runtime.json` 自动发现端口。Clawd 未运行时不阻塞 GrayCode；恢复连接后同步最新状态，运行中的任务定期报告状态。关闭联动或退出 GrayCode 时结束已报告的会话。Web 模式连接的是 **GrayCode 服务端所在电脑** 的 Clawd。旧设置保持未启用，备份恢复后需重新启用并确认本机注册信息。

## 3. 屏幕感知（Screen Perception）

屏幕感知功能允许模型在后台按需或周期性观察你的屏幕变化：

- **手动触发与先览**：用户随时可以在输入框点击“截屏发送”或在屏幕感知面板中预览当前捕获画面。
- **周期性自动感知**：可设定定时采样间隔（如 30 秒或 60 秒），让模型持续关注长耗时的编译、安装进度或设计调试过程。
- **安全与控制**：屏幕感知面板提供明确的开始/停止开关，并设定最大连续捕获次数，防止后台无休止抓屏。
