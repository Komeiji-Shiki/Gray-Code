# 编码、审阅与工作树

## 工作区与会话

工作区定义文件和命令的执行目录，可以包含多个根目录。对话绑定工作区后，文件读取、搜索、修改和终端都使用这份绑定。导航到另一项目与修改已有任务绑定有各自入口。

文件树展开目录后按视口渲染可见行。滚动、选择和键盘导航仍按真实路径工作；目录变化合并后刷新受影响的父目录，切换项目时过期的展开结果不会覆盖新项目。

## 编辑与搜索

编辑器支持未保存草稿、语言服务、补全、参数提示、诊断与快速修复。搜索能覆盖磁盘文件与打开文档的草稿。文件保存与模型改动继续经过对应文件服务和差异审阅流程。

常用操作包括 Ctrl+S 保存、Ctrl+空格 或 Ctrl+J 打开补全、Ctrl+Shift+空格 查看参数提示。底部问题入口按文件和错误定位。语言服务是否可用取决于当前语言与配置。

工具读取可以在同批确认独立时并行执行，最多四个。文件写入、命令、需要确认的工具与界面操作保持原有执行顺序。

## 终端与命令

模型命令执行和交互终端共用明确的工作区范围。命令结束后保留可查询结果，释放活动进程对象和监听器。后台服务按其实际生命周期管理；结束一轮模型对话并不等于停止所有后台程序。

停止操作使用服务持有的进程对象。退出等待有明确结果，进程树终止失败会报告错误。运行记录中的活动命令数量只描述工作区命令服务，不表示整个系统的全部进程。

## Git 与工作树

Git 面板提供状态、差异与工作树管理。工作树是独立目录，可以让另一个任务使用自己的分支和文件状态。

1. 在 Git 面板创建或选择一个工作树。
2. “打开”用于浏览对应项目。
3. “新建任务”将该目录登记为工作区，并在其中创建新的编码会话。

已有会话仍使用原工作区。新任务入口不会把正在进行的任务切换到另一检出目录。工作树删除、合并和推送通过对应明确操作完成。

## 消息修改与结果审阅

用户消息支持编辑重试，模型回答支持重生成；候选分支可以切换并继续。任务状态、工具结果、差异和检查点应一起查看，切换回答候选与回滚源码有各自操作。

归档/恢复用于项目与对话的组织。代码文件存在工作区，应用数据备份保存会话与记录；备份应用数据不复制整个项目源码。
