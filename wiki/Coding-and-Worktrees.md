# 编码、审阅与工作树

[返回目录](Home.md)

GrayCode 提供了一整套专为本地工程开发设计的编码工具链，包括实时代码检索、智能修改、Diff 审阅、终端集成以及 Git 工作树（Worktree）多任务并行。

---

## 1. 工作区与项目管理

- **工作区绑定**：每个会话可以绑定一个或多个本地工作区目录。绑定的工作区是模型读取、搜索、编辑代码以及执行终端命令的基准根路径。
- **多根工作区**：支持在一个会话中同时引入多个不同代码仓库，适合微服务或前后端分离项目的跨仓库联调。
- **文件树与实时监听**：左侧文件树采用高性能虚拟化渲染，在大型项目中也能极速滚动与展开，并在文件发生变动时智能增量刷新。

---

## 2. 代码检索与安全修改

### 智能代码检索
模型内置了轻量级、针对工程优化的检索工具：
- **`search_in_files`**：基于关键字或正则表达式在整个代码库中快速定位符号、函数与定义。
- **`read_file`**：支持按行号范围精准读取，避免不必要地将整个大文件塞满上下文窗口。
- **语言服务（LSP）集成**：支持符号跳转（`goto_definition`）、查找引用（`find_references`）与结构大纲（`get_symbols`）。

### 安全修改与 Diff 审阅
- **非破坏性修改**：模型修改代码时，系统会生成清晰的 Diff 预览卡片。
- **修改前确认**：你可以直观审阅修改前后的每一处变更（高亮显示增删改），确认无误后点击“应用”，或者在聊天中指出需要调整的细节。
- **多文件批量修改**：支持在单轮响应中并行规划并应用多个独立文件的修改，大幅提高开发效率。

---

## 3. 终端与命令执行

- **命令执行控制**：模型能够借助 `execute_command` 运行编译、构建、测试以及脚本命令，并在卡片中展示实时输出。
- **安全审批策略**：对删除、安装或高风险系统命令提供拦截和明确的手动确认提示。
- **多 Shell 支持**：在 Windows 上支持 PowerShell、CMD、Git Bash 与 WSL，可根据实际开发环境在设置中切换。

---

## 4. Git 与工作树（Worktree）并行任务

当你需要让 AI 同时处理多个互不相干的需求（例如一方面重构模块 A，另一方面排查紧急 Bug B）时，使用 **Git Worktree** 是最佳实践：

1. 打开左侧 **Git** 面板，进入工作树管理区域。
2. 点击 **新建工作树**，输入新分支名称与检出目录。
3. 点击 **新建任务**：系统会自动将该独立检出目录绑定为一个新会话，在该分支上开始独立编码。
4. 两个会话各自操作独立的文件树，不会产生 Git 冲突，任务完成后可直接在 Git 面板完成分支合并或推送。

---

## 5. 树状会话与分支探索

在长对话和复杂重构中，往往需要尝试不同技术方案：
- **编辑重试与重生成**：修改历史消息或点击重新生成时，GrayCode 不会覆盖掉原有的回答，而是自动分叉出一个候选分支。
- **随时回溯**：你可以通过消息底部的分支指示器（例如 `2/3`）在不同思路之间任意切换。
- **联动存档点（Checkpoints）**：切换对话分支时，可选择同步回滚对应的工作区代码快照，让你大胆尝试实验性重构而无后顾之忧。
