# ChatGPT 订阅登录

在设置的渠道页新建或选择 OpenAI Responses 渠道，将认证方式改为“ChatGPT 订阅”，点击 **Continue with ChatGPT**，在系统浏览器中登录并允许 GrayCode 使用订阅额度。完成后返回 GrayCode 获取模型、选择模型，再保存设置即可发送请求。

授权直接使用 OpenAI 的 Sign in with ChatGPT 流程和公开 Responses API。GrayCode 自己管理登录与令牌续期，无需单独运行 Codex 或中转服务。首次成功授权会说明订阅用量，并提供 ChatGPT 的用量管理入口。

桌面版使用系统加密存储。独立服务器需要通过 --key-env 指定含有 32 字节十六进制密钥的环境变量；没有加密存储时，登录入口会说明原因并禁用授权操作。

订阅认证自动回传有效思考签名与摘要，明文思考只保留在本地显示。思考回传、DeepSeek Vision 图像预处理和 OpenCode Go 会话标识在订阅模式下隐藏，旧兼容选项不影响官方请求；切回 API Key 认证后恢复原有设置。

订阅请求沿用服务端缓存策略，自动发送稳定的 `session_id` 会话请求头，并过滤订阅模型不支持的 `prompt_cache_options`。已设置正文缓存 key 时，会话请求头使用同一标识；未设置时按对话生成不含原始 ID 的稳定标识，无需单独配置。缓存用量分别记录读取与写入，读取为零和上游未返回会保持区别；实际命中量以官方回执为准，订阅回执的缓存写入量为零不代表没有建立缓存。

同一渠道可以保存多个账户或工作区注册，选择器会同时显示账户名称和注册标识末尾，便于区分相同邮箱的不同工作区。重新登录已有账户会复用它的应用注册；添加账户或工作区会进行新的授权。退出会尝试撤销该账户的可续期会话，并清除本机令牌；远程撤销未确认时，界面会明确提示。

登录回调监听在运行 GrayCode 的机器的 `127.0.0.1`。如果浏览器没有自动返回应用，或者浏览器与服务运行在不同机器上，可将浏览器最终地址栏里的完整回调地址粘贴到渠道设置中完成登录。离开渠道认证界面会取消未完成的登录，不会退出已经保存的账户。

订阅请求始终使用流式输出并关闭远程存储，每轮发送所需历史，保留工具结果和有效思考签名。温度、Top P、输出 Token 上限及其他订阅接口不支持的参数不会发送；普通 API Key 渠道继续保留其原有参数。订阅渠道的默认 Token 计数使用本地估算，模型列表来自当前授权账户。获取模型时携带 GrayCode 的实际版本（`client_version`），避免官方接口因缺少版本而返回旧目录；按官方返回的可见性与顺序展示模型。

API Key 和订阅令牌分别存放在平台的加密凭据存储中。订阅会话只保存在本机，设置导出与便携配置不复制订阅令牌；导入旧配置时也会忽略其中的订阅会话，保留本机已经轮换的新令牌。API Key 仍随配置携带，订阅凭据随平台数据备份保留。切换认证方式不会覆盖已有 API Key。同一电脑继续使用相同应用数据目录时，换用新便携程序会复用原登录；访问令牌到期由程序自动续期。若上游确认续期令牌失效，需要重新登录，错误会保留具体的上游错误码。遇到订阅用量限制时，通过“管理订阅用量”查看账户或应用的限制。

自动续期沿用官方 SDK 的到期前一分钟窗口，并遵守官方返回的 `earliest_refresh_at`，未到允许时间时继续使用尚未过期的访问令牌。并发请求合并后会重新读取当前凭据，避免延迟返回的旧记录再次使用已经轮换的令牌。收到轮换令牌后，会先保存到本机加密记录，再验证新的身份令牌；验证暂时失败或重启时恢复这份记录，不重复使用已被消耗的旧续期令牌。正常退出会等待已经开始的续期完成。

续期的网络故障或服务端暂时故障会保留登录。只有上游确认续期令牌不可用时才清除令牌并提示重新登录；提示保留错误码、脱敏后的具体原因、HTTP 状态及上游请求 ID，便于定位服务端失败。

接口要求以 [官方注册与登录文档](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[账户与续期文档](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)、[模型与推理文档](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference) 和 [预览限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations) 为准；续期窗口与轮换处理参考[官方 SDK 实现](https://github.com/openai/sign-in-with-chatgpt-devkit/blob/main/packages/local/src/index.ts)。
