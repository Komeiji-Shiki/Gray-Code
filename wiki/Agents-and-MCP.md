# 工具、Skills 与代理

[返回目录](Home.md)

GrayCode 拥有高度可扩展的工具体系，支持标准 **MCP（Model Context Protocol）**、**Skills 技能库**、**原生 Sub-Agents（子代理）** 以及 **外部 ACP 编码代理**。

---

## 1. MCP（Model Context Protocol）扩展

GrayCode 原生支持 Anthropic 发起的 MCP 开放协议，允许你将数据库查询、浏览器自动化、外部 API 等任何服务无缝接入为 AI 工具。

### 添加 MCP 服务器
进入 **设置 → MCP**，点击添加配置：
- **传输类型**：
  - **`stdio`**：通过本地可执行程序（如 Node.js 脚本、Python 脚本或二进制文件）启动，配置命令与启动参数。
  - **`HTTP / SSE`**：连接远程或本地 HTTP / Server-Sent Events 协议的 MCP 服务。
- **参数说明**：
  - **连接与请求超时**：默认为 30 秒（`30000ms`），对耗时较长的数据分析或网页爬虫服务，可按需延长至 60 秒或更长。
  - **Schema 清理**：针对部分严格校验 JSON Schema 的模型端点，可自动移除多余的 `$schema` 或限制性声明，提升兼容性。

配置保存后，点击 **连接** 即可在工具列表中看到发现的工具、资源与 Prompt 模板。

## 2. Skills（技能体系）

Skills 是封装了特定领域规则、标准工作流或项目脚手架的可复用指令集。

- **多层级加载**：
  - **全局技能**：位于用户配置目录，所有项目会话均可调用。
  - **项目专属技能**：存放在当前项目工作区的 `.graycode/skills` 目录下，随代码仓库一起进行 Git 版本管理。
- **按需调用**：模型会根据用户意图，通过内置的技能工具按需检索并加载完整工作流，节省全局提示词预算。

---

## 3. 原生 Sub-Agents（子代理协作）

在处理大型工程任务时，主模型可以将具体工作派发给子代理。子代理拥有独立的上下文和执行环境，支持前台即时等待或后台异步运行。

### 子代理并发与调度
在 **设置 → 子代理** 中可根据机器配置调整运行参数：
- **最大并发数**：控制后台同时运行的子任务数量（默认 3）。
- **默认迭代轮数**：限制单个子任务与工具交互的最大轮数（默认 80），防止死循环。
- **任务超时限制**：通用 Worker 默认运行时长为 40 分钟，主模型可在派发任务时动态覆盖。
- **协同与状态通知**：后台运行的子任务完成时，结果会自动以卡片形式回流至主对话窗口，无需用户手动轮询。

## 4. 外部 ACP（Agent Client Protocol）编码代理

如果你更习惯使用专用终端编码代理（如 **Kimi Code** 或 **Claude Code**），可以通过 ACP 协议将其作为后端接入 GrayCode：

### 配置示例（Kimi Code）
进入 **设置 → 开发 → 外部编码代理**：
- **名称**：`Kimi Code`
- **启动命令**：`kimi`
- **参数**：`acp`
- **环境变量**：按需填入 API Key 及其他配置

### 交互与权限管理
- **原生终端体验**：GrayCode 负责建立长连接、转发提示词、展示流式输出与进度。
- **细粒度权限审批**：外部代理发起的敏感文件读写或终端执行，会在 GrayCode 界面上展示清晰的单次/持续允许卡片。
- **会话持久化与恢复**：支持在工作区重新打开或恢复历史代理会话。
