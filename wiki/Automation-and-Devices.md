# 自动任务、Bot 与远程设备

[返回目录](Home.md)

## 自动任务

自动任务有目标、定时和事件触发形式。配置保存目标、来源会话、模型与工作区选择；一次触发通过现有运行核心执行。目标任务继续已有上下文，定时与事件任务按对应规则产生输入。

任务面板提供状态、进展、暂停、继续和删除。需要工具确认或文档确认时，任务等待真实输入；失败与取消保留原因。用户在同一会话开始新的消息会暂停对应自动执行，避免两条流程同时修改同一会话。

事件触发记录事件身份和来源关系。当前配置决定忙碌时如何处理后续事件，以及重启后如何恢复；重复状态通知不等于新事件。结果和领取状态在事务中记录，完成反馈沿原任务来源返回。

## 子代理等待与恢复

子代理可以加入共享团队，领取有依赖关系的工作。事件等待先补读已有记录再订阅后续变化，避免等待注册与事件提交之间丢失通知。等待时释放并发席位，取消后清理订阅。

应用重启后读取保存状态，按原任务规则恢复或显示中断。取消、失败、无进展和已完成分别呈现；完成回流使用原身份去重。

## Discord 与 OneBot

在各自设置页配置凭据、启用范围和账号绑定，保存后连接。平台读取真实入口的发送者和频道身份，并将消息接入共享任务服务。任务结果、确认与回执保留原消息来源。

Discord 提供交互面板，普通工具确认可直接选择，外部代理的多个权限选项通过分页选择保留完整 ID；完整操作信息可以随面板附件查看。文字命令中的具体选项使用：

~~~text
/gray choose <请求ID> <从1开始的选项序号>
~~~

CLI 使用对应的 choose 命令。普通允许/拒绝流程保持原入口。已经处理或过期的请求 ID 不能确认下一次请求。

回复显示的更新间隔为 1～60 秒，表示逐步编辑频道消息的最短等待时间。较短间隔便于查看进展，较长间隔减少编辑次数；回复完成时会补齐全文。它不控制模型生成速度。

时间总结初始间隔为 30 分钟，空闲规则从最后一条消息计时，固定间隔从上次总结尝试计时。后台每 30 秒检查，等正在运行的任务完成后处理；失败按配置间隔重试。压缩比例初始为 80%，提高会让更多较早原文改用摘要，降低则保留更多原文，实际范围按完整回合对齐。

流式内容与最终回复沿投递服务发送；断线或回执不完整时记录原消息和未知状态。重新连接依据持久记录补取结果，不重新执行已经派发的任务。

## 配对执行设备

每台节点拥有自己的数据目录和任务核心。配对时选择允许的账号、工作区、任务和电脑操作范围。连接后可查看远端项目、启动或继续本配对创建的任务、读取事件、确认工具、审阅差异和取消任务。

~~~mermaid
flowchart LR
  A[控制设备] -->|配对请求身份| B[执行设备]
  B --> C[远端任务与工作区]
  C --> D[持久运行记录]
  D -->|状态与事件补取| A
~~~

新节点的能力信息包含电脑截图是否可用、图片坐标版本和支持动作。旧节点可以省略新字段。当前电脑操作宿主以 Windows 为主；远端文件与命令使用执行设备上的项目目录。

断线会释放对应的电脑控制权，运行记录仍保留。恢复连接后查询原请求和事件。设备撤销会停止新请求；已有任务执行前继续检查其来源授权。

## Web 与手机

Web 工作台共用聊天、设置、文件、终端和任务数据。手机浏览器的文字输入区用于中文和软键盘输入；远程画面支持点击、拖动、滚动和按键。Web 端不提供 Electron 内置浏览器的全部宿主能力。

本地可控 HTTP、TLS 和 Bot 夹具覆盖消息路由、去重、确认和重启恢复。真实公网、真实 Bot 频道、双设备和手机软键盘的验收需要对应部署环境，详见[验证范围](Performance-and-Validation.md)。
