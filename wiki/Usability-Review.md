# 交互设计与可靠性规范

[返回目录](Home.md)

GrayCode 围绕开发者真实使用场景，建立了一套注重安全、可恢复性与操作确定性的交互设计规范。

---

## 1. 操作安全与确认机制

AI 编程助手在本地拥有真实文件与系统执行权限，因此安全边界至关重要：

- **代码修改前的 Diff 审阅**：所有的代码写入均通过结构化 Diff 呈现，高亮修改区域并等待用户确认，杜绝静默覆盖。
- **敏感终端命令拦截**：针对文件删除、包安装或具有潜在系统破坏性的命令提供明确审批卡片。
- **权限单次与持续授权**：对于外部 ACP 代理或 MCP 扩展的权限请求，支持细粒度的“允许一次”或“本会话持续允许”，并在界面保留完整的决策日志。

---

## 2. 状态恢复与抗中断设计

- **部分回复（Partial Response）持久化**：当网络中断、服务端异常或用户主动点击“停止”时，已接收到的流式文本与工具执行状态均会完整保留并打上中断标记，用户可随时接续生成或在此基础上重新发起。
- **统一草稿生命周期（Draft Lifecycle）**：在设置页面或角色配置中切换分类时，未保存的输入与 JSON 修改会自动保存在内存草稿中，避免因界面切换导致辛辛苦苦编写的内容丢失。
- **任务与进程生命周期管理**：后台运行的子代理、终端命令与浏览器会话拥有独立的执行上下文与退出超时控制。命令仍在运行时关闭主窗口，会保留后台工作；退出应用时清理自己持有的进程树。清理失败会报告具体组件，保留未完成的资源供再次退出时重试；清理期间重复退出不会提前结束应用。

---

## 3. 图形交互与多模态反馈

- **观察与动作解耦**：在电脑控制（Computer Use）与浏览器操作中，动作执行结果与后续屏幕捕获相互独立。即使动作执行成功但随后的截图因窗口切换失败，系统也会清晰区分状态，避免误报导致重复操作。
- **无障碍与直角设计语言**：全站遵循清晰、克制、高对比度的平面暗色直角设计规范，减少视觉噪音，提升长时间编码的专注度。

## 4. 桌面退出、安装与窗口恢复（2026-09）

关闭没有未保存内容的窗口时，正在运行的后台任务仍会继续；任务完成后应用按原有策略退出。“最小化到托盘”是主动常驻，不会因任务结束自动退出。有未保存文件或设置时，对话框逐项列出原因，默认焦点为“继续工作”；有后台任务时可选择“后台运行”，保留当前窗口和修改。只有明确选择退出，才停止任务并放弃未保存修改。

退出时显示结束备份、关闭桌宠与浏览器、停止任务连接等真实清理阶段，不使用模拟百分比，不设置强制退出倒计时。失败后保留现有重试机制。确认窗口的预加载失败时保留默认取消的系统对话框作为兜底。安装、回退继续使用既有完整包校验、数据备份和回退点保护。

安装器使用构建时生成的品牌画面，进入应用后，更新设置页统一展示当前版本、下载操作、待安装版本与恢复点。已知下载百分比显示有界进度，备份等无比例的阶段显示不定进度。下载期间仍可访问发行页面和恢复目录。窗口隐藏暂停轮询，恢复可见时补读状态，关闭面板后不再发起请求。

窗口大小、位置和最大化状态存放在数据目录的 `desktop-window.json`，连续拖动合并写入。恢复位置按显示器逻辑工作区裁剪；拔掉副屏或改变缩放后，窗口不会留在屏幕外。损坏偏好或写入失败不阻止应用启动、退出。

## 5. 编辑、终端与键盘交互

编辑器在宿主处理速度较慢时合并尚未发送的连续全文修改。保存、关闭和外部刷新仍是顺序屏障，屏障两侧的内容不混合。外部文件变化刷新保留文档身份并递增版本；刷新期间到达的新输入随后按顺序应用。已经变脏的文档不被磁盘内容覆盖。

终端切换成功接续输出后才允许输入。切换失败、旧请求晚到或面板卸载后，旧画面不会把键盘输入发送给另一会话。相同会话可以显式重新连接。

共享模态框通过独立的模态栈处理 Esc 和 Tab；焦点临时丢失时只操作最上层，隐藏和禁用控件不进入焦点循环，关闭下层弹窗不会抢走上层焦点。
# 桌面审计后续行为（2026-09-29）

工具结果的等待、成功和失败按实际回执显示。读取同一文件的多个行范围可以分别展开和复制，点击结果中的文件路径会定位对应行。混合成功和失败的批次显示“部分成功”，同时保留失败原因和已读取内容。工具返回的图片可以直接打开附件查看器，使用与用户图片相同的缩放、旋转和关闭操作。

图片查看器以画布中心定位图片，窗口变窄或旋转图片后重新适配显示范围。窄窗口中的文件名、保存和关闭入口保持可见；桌面 smoke 会用大图片在 900、420 和 360 像素窗口及旋转状态下验证真实边界。

退出时有未保存内容会提供“保存全部并退出”。应用先完成编辑器排队更新，再逐个保存文件和设置；保存期间使用模态进度窗口，防止新输入跨越保存确认。文件冲突、表单校验错误或界面失联都会保留窗口，显示失败原因并定位需处理的文件或设置。默认仍是继续工作，原有后台运行和放弃修改退出保持独立。

启动失败时可重试、打开日志目录，或从另一个数据目录启动。选择其他目录通过下一次启动的 `--data` 参数生效，原目录和迁移记录保留；进入应用后仍可使用设置中的备份恢复入口。恢复界面不自动开启屏幕采集或模型任务。

退出窗口保留对话框语义、默认取消和键盘焦点循环，增加高对比度样式及长文案换行。错误复制在外壳和聊天使用同一脱敏函数，清除常见授权头、Cookie、密钥字段和 URL 凭据；各业务域的重试仍沿用其原有的目标和权限校验。

安装服务的回归覆盖更新包校验、备份失败、文件占用、取消、恢复版本不匹配和重启失败等分支。Setup.exe 首装、真实断电、卸载数据策略、真实屏幕阅读器及多刷新率显示器仍属于独立验收范围，不能由组件测试替代。

## 桌面审查与远程恢复（2026-09-30）

差异面板按修改记录统计，待处理与已处理分组显示。同一个文件可以有多条记录。列表请求和接受操作均绑定当前工作区；切换项目后，旧请求的内容、错误和操作回执不会覆盖当前面板。工具预览按实际提案定位工作区、文件和工具调用，最近列表以外的指定记录也可载入。窄面板中列表可折叠，接受和拒绝保持在可见的底部操作区。

停止请求覆盖尚在排队、准备提示词或提交运行记录的输入。界面继续接收实际运行结果，只有服务端确认旧任务释放后才结束等待；取消失败或超时显示原因，仍可重试。移除项目后清理失效的界面选择，历史会话继续沿用已有访问规则。

刷新独立桌面或 Web 页面后恢复原当前对话。恢复期间的新导航或输入优先于启动位置；已移除或不可访问的会话不自动创建替代历史。旧会话的摘要、打开、编辑和重生成回执按原会话处理，不覆盖新会话或把用户从设置页带回。

远程连接需要重新取得快照时，外壳设置、文件树、Git 和编辑器同时重新核对状态。短暂断线保留原资源；默认 30 秒宽限过后释放该客户端持有的语言服务和写入锁，保留未保存正文与原磁盘哈希。重连后仍能读取原草稿；若磁盘已由其它操作改变，保存会报告冲突。

离线文档与设置草稿保存在运行中的服务内存里。桌面退出、重启、安装回退或应用备份前会检查这些草稿；远端草稿需从原远端页面保存，退出确认会列出它们，并提供明确的放弃操作。强制结束进程不保证恢复内存草稿。

导航菜单、确认表单和设置页支持焦点进入、Tab 循环和 Escape。设置中有未保存内容时先打开确认层，再次 Escape 只关闭该层；返回对话后焦点回到原设置入口。待回答与待确认有不同的可见文字，设置分类分为五组，构建和程序诊断信息按需展开。托盘提示说明是否等待后台任务结束后退出，安装器品牌画面默认采用中文。
