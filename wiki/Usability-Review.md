# 易用性与性能检查记录

本记录对应 2026-09-22 的源码改进，覆盖桌面工作台、聊天、电脑操作、Live2D、长期记忆、导入资料、设置、子代理、MCP、ACP 和工具上下文。配置说明以实际读取与执行路径为依据，数值的含义、特殊值和使用场景同时写在界面及对应手册中。

## 主要问题与处理

| 使用场景 | 检查发现 | 当前行为 |
| --- | --- | --- |
| 配置 Live2D、屏幕感知、记忆和自动任务 | 数值只有名称，难以判断调高后的效果 | 说明单位、初始值、特殊值、适用场景及资源或上下文影响，详见[记忆与陪伴配置](Memory-and-Companions.md) |
| 查找新功能配置 | 搜索向量配置会进入旧记忆页，Live2D 与屏幕感知的入口分散 | 记忆和外观设置提供专用面板直达按钮，搜索可以定位，打开后保留设置草稿 |
| 使用 General Worker | 运行时长固定为 40 分钟，无法表达任务差异 | 40 分钟作为初始默认值；用户可修改默认秒数，主模型可用本次 maxRuntime 覆盖。显式暂停保留剩余时长 |
| 快速保存或撤销总结设置 | 400 毫秒延迟保存未接入统一草稿，最后输入可能漏存或在撤销后重新写入 | 保存与跳转先提交输入，撤销先取消未发送的定时保存，旧扩展保留离开时保存行为 |
| 输入工具迭代上限 | 0、小数或小于 -1 的数值在保存时被静默忽略，重新打开才恢复原值 | 原输入旁显示原因，无效时阻止保存和切换；正整数、-1 与清空保留原值的语义不变 |
| 在设置分类之间切换 | 未完成的 JSON 校验失败后，表单仍卸载，原始输入丢失 | 切换前校验并暂存草稿；失败留在原分类，修正后再切换，最后统一保存 |
| 选择角色、世界书或桌宠资源 | 切换对象和窗口跳转可能覆盖未保存编辑 | 草稿与原对象绑定，跳转及关闭经过相同的保存或放弃流程 |
| 操作电脑 | 截图、控件树与动作混在同一窗口，旧观察和新动作状态容易混淆 | 截图成为主视图；控件树按需打开，支持尺寸、缩放与动作选择，坐标按实际图片映射 |
| 隐藏远程电脑面板 | 打开设置后仍可持续采集，迟到的请求可能重新保留控制权 | 设置可见状态传递到面板；隐藏后停止采集，迟到取得的控制权立即释放 |
| 动作执行后截图失败 | 容易把截图失败当成动作失败并再次执行 | 动作回执与后续观察错误分开，保留已完成动作的身份 |
| 核对大量长期记忆 | 相关性召回的预算和数量限制妨碍逐条浏览 | 人工分页与相关性搜索分别提供；正文按需展开，可筛选确认状态、有效性并查看确切历史修订 |
| 编辑记忆与查看关系 | 整段改写耗费输出，实体关联和版本依据混用 | 支持唯一匹配替换、追加与整段修订；图谱区分实体关联和来源依据，更新实体不再误使普通关联事实失效 |
| 导入 LifeBook | 原日志、图片、索引与图谱信息无法只靠文本条目完整表达 | 原件按字节归档，可编辑条目单独保存；图谱在副本上恢复和导出，完整备份包含原始附件 |
| 停止或中断生成 | 已经显示的部分正文在停止后消失 | 保存已收到的普通正文、稳定消息身份和来源，并标记为部分回复，可继续或重新生成 |
| 对话列表的消息数量 | 前端旧摘要可能少算或多算实际历史 | 从已提交的历史索引取得真实条数，迟到摘要也按真实数量校正 |
| MCP 工具兼容 | Schema 清理开关未接通，部分错误结果丢失结构或附件 | 清理仅作用于模型声明；执行按原始约束及声明版本校验，错误详情、图片和其他附件继续保留 |
| 工具说明与结果体积 | 命令工具重复多套教程，MCP 重复返回同一份 JSON | 按可用 Shell 组织规则，保留关键转义说明；只删除经核对完全相同的 JSON 文本副本 |
| 聊天首次加载 | 差异编辑器及完整数学、语法库进入初始依赖 | 差异面板按需打开，遇到公式或代码后再加载完整对应库 |
| 建立记忆嵌入索引 | 混合命中缓存时仍重发整批，重复文本重复请求 | 仅发送缺失且不同的文本，再恢复原记录顺序和条数；整批校验通过后才更新缓存 |
| 查看运行记录 | 慢刷新相互重叠，收起的详情仍提前生成整段 JSON | 密集刷新合并后补读最新状态，展开详情时才生成完整正文，关闭后停止补读 |
| 查看设置预览 | 隐藏的设置页仍轮询，慢请求可不断重叠 | 只在可见的设置页面刷新，同一时刻保留一轮预览请求 |
| 限制诊断上下文 | 截断没有提示，零预算可能被描述成没有错误 | 明确标记被省略的诊断及文件，区分没有问题和配置不提供诊断 |
| 使用裁切、缩放和旋转工具 | 中间图片先按原格式编码，之后再次编码目标格式，增加耗时并可能重复有损压缩 | 在同一处理链直接编码最终格式；旋转输出 PNG/WebP 时保留应有的透明区域，裁切默认坐标模式与声明一致 |
| 图像编码期间取消 | 开始编码前检查取消，编码完成后仍可能交给宿主保存 | 保存前再次检查取消，取消结果沿原流程返回，避免已经取消的操作继续写入文件 |
| 导入长截图作为背景 | 只限制缩略图宽度，细长图片仍会生成很高的画布 | 缩略图宽高都限制在 320 像素内，小图不放大，原图及原始尺寸完整保留 |
| 打开和关闭桌宠 | 旧加载失败可能干扰新窗口，失败对象挡住重试 | 根据窗口身份忽略过时结果，真正加载失败后释放对象，允许后续重新加载 |

共享控件、旧聊天卡片、工具面板和弹窗使用统一的直角变量。代码高亮沿用主题颜色，较长的配置说明使用正文排版；头像、状态点和动画笔画保留各自的图形用途。

## 记忆与导入的取舍

记忆工具参考了 [Nocturne Memory](https://github.com/Dataojitori/nocturne_memory) 的分层读取与精确修改交互，继续使用 GrayCode 已有的来源、修订、时效和删除传播规则。主题目录与长正文都能分段继续读取，工具会明确返回预算不足、分页位置或省略信息。

导入资料库先用于浏览、编辑和核对，自动召回初始关闭。用户开启资料库后，已确认且当前有效的条目才能参与私人真实记忆的自动召回。群聊、角色剧情和导入资料保持各自的范围；自动提取继续写入原有的个人、项目或群组记忆。

原始 Markdown、对话日志、图片、数据库与索引完整归档。编辑条目产生新修订，原件用于核对和回退。模型及输入前缀未知的旧向量作为原始索引保留；已知且文字未变的现有向量可以在修订时复用。具体操作见[记忆迁移](Memory-Migration.md)。

| 聊天启动 JavaScript | 约 1.61 MB | 约 1.35 MB | 同一构建方式，完整数学与语法库改为按需加载 |

这些数字描述对应样本和本机执行条件。工具目录取决于实际启用的功能，模型端 token 计数和计费取决于所用服务。完整说明见[性能与验证](Performance-and-Validation.md)。

## 验证方式

本轮集中平台回归覆盖 94 套、388 项用例。首次运行有 387 项通过；剩余一项的旧数据库夹具保留了新版字段，修正夹具后，快照、存储与记忆迁移的 14 项相关用例复验全部通过。后续图像编码与取消调整另通过 12 项真实 Sharp 测试；设置、桌宠、电脑面板、渲染和记忆图谱按改动运行对应前端回归。完整类型检查、三语映射检查与桌面联合构建也已完成。

代码修改按对应职责验证：存储与迁移检查版本、来源、事务和附件完整性；工具检查原始约束、结果内容和错误保留；聊天检查取消、候选切换及重新打开；设置检查草稿、无效输入、加载竞态和页面生命周期。

真实 Web 工作台连接实际后端和存储，使用本地模型替身检查发送、编辑、重生成、取消及配置交互。公式、TypeScript 和 Mathematica 使用完整渲染库在实际页面核对。大规模试迁移库另行检查了记录分页、来源关系图、原件校验和图片预览。

桌面主进程、预加载、Windows 电脑宿主、工作台和聊天前端完成联合构建。窗口与控制竞态通过隔离测试覆盖；外部模型、ACP 登录和具体设备仍按各自部署配置运行。

后续变更可从对应的测试文件继续回归，例如 [部分回复](../packages/core/tests/runtimePartialResponse.test.ts)、[工具目录](../packages/core/tests/toolRegistry.test.ts)、[上下文恢复](../packages/core/tests/contextManagement.test.ts)、[记忆关系界面](../frontend/src/__tests__/components/MemoryLibraryGraph.test.ts)和[设置草稿](../frontend/src/platform/__tests__/settingsDraftLifecycle.test.ts)。
