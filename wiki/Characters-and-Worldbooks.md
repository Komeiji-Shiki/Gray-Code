# 角色卡、世界书与正则

[返回目录](Home.md)

资料库支持导入 SillyTavern 生态的角色卡 PNG/JSON、世界书和正则规则。角色卡中的内嵌世界书与随卡正则会独立保存，并保留绑定关系；额外资料可以在角色对话配置中追加。

世界书只有命中关键词、常驻条件、时效条件或向量条件的条目会参与注入。具体插入位置由模式预设中的角色与世界书模块决定，深度条目和命名出口沿用各自的位置配置。

世界书最大注入 Token 留空时，按本轮实际选择模型的上下文窗口分配 5%。例如上下文为 128000 Token 时，预算为 6400 Token。模型列表未提供窗口时，沿用渠道上限和平台现有上下文默认值。填写具体数字会覆盖自动预算，填写 0 则关闭世界书注入。每本世界书自己的预算也会继续限制该书的注入量，激活预览会显示本轮采用的预算。

关键词扫描只读取条目所需范围内的最近消息，条目自己的范围优先于世界书与对话配置。递归扫描使用经过宏和世界书正则处理后的最终注入正文，因此后续条目看到的文字与模型收到的世界设定一致。概率、分组、粘滞和冷却条件在新回合重新求值；工具迭代、继续和重新生成沿用该用户回合已经捕获的结果。

启用 `vectorized` 或使用 `activationMode: "vector"` 的条目会复用「资料库 → 长期记忆 → 整理方式」中配置的嵌入服务。按条目的扫描范围和额外来源生成查询，使用现有向量线程排序，候选数量沿用该整理方式的召回数量，再服从世界书的概率、分组和 Token 预算。世界书只使用嵌入配置，不会写入真实事实记忆。

首次向量激活会为条目建立内存矩阵，后续回合复用；正文、正则、宏、嵌入模型或接口变化后重新计算。只读预览不会发起新的嵌入请求，尚未缓存时会说明原因。未配置嵌入服务或服务失败时，普通关键词条目仍能注入，向量条目的原因会显示在激活结果中。

历史记录保存世界书正文一次，并以引用记录模块、深度插入和出口。相同回合在用户消息、模型消息及请求快照中共享存储对象，旧格式历史仍可读取。编辑已有文字继续使用该消息捕获的正则，重新生成恢复原回合的设定和随机结果；新资源版本不会改写过去的对话。
