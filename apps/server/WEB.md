# GrayCode Web 入口

Web 端复用桌面的聊天、设置和文件工作台，提供模型任务、审批与异步问题、工作区目录选择、文件编辑、Diff、Git、原生终端、设置导入导出和背景图库。目录与终端均位于部署电脑，上传设置文件则从当前浏览器所在设备选择。

手机宽度下使用“工作台／返回对话”切换，对话和文件列表覆盖显示，输入草稿与运行中的任务继续保留。触屏文件编辑复用桌面文档保存与版本检查；桌面宽度仍使用 Monaco。顶部“更多”提供电脑目录选择、资料库和退出登录。

选择“更多 → 选择电脑文件夹”，即可浏览部署电脑的磁盘、目录和目录链接，并按名称筛选当前目录的子文件夹。路径导航保留网络共享根路径；选择后注册为工作区，工作台显示该电脑中的文件。工作区下拉菜单也提供添加入口，晚到的旧目录结果不会覆盖新的选择。

输入栏的“预览当前完整提示词”会按实际发送流程组装当前草稿、附件、历史、预设、固定文件与工具声明，可按消息阅读、搜索和复制完整 JSON。预览只作本地投影；若发送前预计需要自动总结，会显示说明并保留总结前的内容。角色对话会展示本次世界书激活结果；设置中的预设条目也可直接添加角色卡或世界书变量，随后调整顺序与消息角色。

“更多 → 自动任务”可以创建、查看和暂停长期目标与定时任务，并调整预算后继续。关闭网页不会停止运行；应用重启后长期目标等待手动继续。触发时间、预算口径和恢复行为见 [自动任务说明](AUTOMATIONS.md)。

交互式终端由核心统一持有，主人登录的桌面与网页共享终端列表。新建增加一个终端，停止结束所选进程，关闭同时移除它的输出。刷新页面、重新登录或停止 Web 入口不会停止核心内的终端；核心退出时终端结束。恢复时读取最近 256,000 个字符，再衔接实时输出；退出码与输出保留到明确关闭或核心退出。

文件列表提供新建文件／目录、重命名或移动、删除、上传，以及网页下载／桌面另存。目标都限定在所选工作区内，未保存的编辑草稿会阻止覆盖、移动和删除。重命名会同步已经打开的文档；删除需要明确确认目录和全部内容，应用内不提供撤销。版本变化时先重新读取，再确认操作。

上传保留原始字节，单个文件最多 64 MiB，多个文件依次处理。存在同名文件时必须勾选替换，执行前再次核对版本；失败或停止后续上传时保留已完成的文件。上传期间离开网页会触发浏览器提示；连接中断时需要刷新确认结果。下载直接传输文件流，支持单段 Range 读取；图片等文件可以通过受认证的内容接口预览，HTML 仍按下文的独立沙箱范围处理。

本阶段通过部署访问令牌登录主人账号，不提供公开注册。令牌可以在桌面设置中生成并加密保存，也可以由启动参数指定的环境变量读取。浏览器登录后使用 HttpOnly、SameSite=Strict 的会话 cookie，令牌不写入 localStorage、sessionStorage 或 URL。标签页分别持有设置草稿，已保存的数据由同一核心管理。会话有效期为 12 小时；重新登录保留当前标签页身份及仍在页面中的编辑内容。

## 在设置中管理入口

打开“设置 → 远程连接”，启用 Web 入口、填写端口和可选的 HTTPS 访问地址，生成随机令牌后先复制，再“保存全部”。所有修改与其他设置共用草稿，未保存时不启动服务，撤销草稿也会放弃新令牌。保存的令牌不会重新显示；忘记时可以在部署电脑上生成新令牌。端口 0 由系统选择，固定反向代理应填写固定端口。

保存后显示实际连接状态、浏览器访问地址与代理上游。“登录设备”列出名称、连接状态和到期时间，允许单独撤销浏览器登录。名称仅用于区分记录。更换令牌会立即撤销全部网页登录和旧 API 令牌；同一端口轮换令牌不会重启监听器。

“停止本次入口”只影响当前进程，下次启动按保存的配置启用；关闭启用选项并保存才会持续关闭。入口启用时，关闭桌面主窗口仍保留后台核心。停止入口、撤销设备和更换令牌都不取消核心任务或交互式终端。通过网页停止入口后，需要在部署电脑上重新启动。

启动参数明确指定 Web 入口时优先使用参数，设置页显示“由启动参数配置”；仍可停止本次入口或撤销登录设备。

## 使用桌面实例的同一份数据

在完成平台、桌面和前端构建后，给桌面入口添加以下参数：

```powershell
npm run desktop -- --data .tmp/desktop-local --web-port 4317 --web-token-env GRAYCODE_WEB_TOKEN
```

`GRAYCODE_WEB_TOKEN` 应事先设置为至少 32 个字符的随机访问令牌。浏览器打开 `http://127.0.0.1:4317/`，使用该令牌登录。Web 端使用桌面实例的系统密钥服务；不需要再次指定加密密钥，也不启动第二个数据库实例。关闭主窗口仍在后台提供已启用的远程入口；明确退出整个应用时，Web 服务与核心一同关闭。

## 独立服务进程

不启动 Electron 时，先构建共享服务和两部分前端：

```powershell
npm run build:platform
npm --workspace @graycode/client run build
npm --prefix frontend run build:platform
npm run platform -- --data .tmp/web-local serve --web --port 4317 --token-env GRAYCODE_WEB_TOKEN --key-env GRAYCODE_STORAGE_KEY
```

`GRAYCODE_STORAGE_KEY` 是另行设置的 32 字节加密密钥，使用 64 个十六进制字符表示。凭据通过 AES-256-GCM 加密保存在平台数据库，加密密钥始终从环境变量读取。后续启动须使用同一密钥。没有 `--key-env` 时仍可使用已配置的 `env:变量名` 凭据引用，但无法在设置页保存新的密钥。

独立服务使用自己的新数据目录。Electron 系统密钥服务与环境密钥的密文格式不同，不能直接互换目录中的凭据；跨宿主迁移配置使用设置导出与导入。

## HTTPS 远程访问

监听地址始终是 `127.0.0.1`。使用自行配置的 HTTPS 反向代理，并显式声明浏览器入口来源：

```powershell
npm run platform -- --data .tmp/web-local serve --web --port 4317 --token-env GRAYCODE_WEB_TOKEN --key-env GRAYCODE_STORAGE_KEY --public-origin https://graycode.example.com
```

桌面实例对应参数为 `--web-public-origin https://graycode.example.com`。域名解析、TLS 和代理由部署者配置；程序不会自动修改防火墙、DDNS 或网络入口。

代理将该来源的根路径转发至 `127.0.0.1:4317`，保留浏览器原始 `Host`，并关闭 `/events` 的响应缓冲。程序校验配置中的 Host 和 Origin，不根据任意 `X-Forwarded-*` 自动信任新来源；HTTPS 入口的 cookie 启用 Secure。当前不支持挂在域名子路径下。

## 当前范围

短暂断线后重放最近最多 2000 条、合计 8 MB 的实时事件。补发完成后再同步界面；事件过期或重新登录时，当前对话自动读取最新历史与运行快照，继续接收后续输出。其他已打开的对话在重新选中时更新，所有输入草稿与附件保留。初始化期间因登录失效而失败的读取会重新加载，顶栏、分支和检查点也随当前对话更新。同步只改变客户端显示，不重新启动模型任务或重复批准操作。

每个客户端的对话和设置视图独立，手机切换设置不会改变桌面的面板。若核心进程已经退出，重新启动后显示持久化的实际任务状态，不会重放进程现场或具有副作用的操作。

HTML 预览用于自包含文件，以独立沙箱显示，不向项目脚本开放宿主接口；外部脚本、请求和相对资源尚未接入。Web 端不提供 Electron 内置浏览器的完整控制界面。浏览器字体可以手动输入名称，当前不请求本机字体枚举权限。

2026-09-09 已通过隐藏 Web 窗口的手机尺寸工作流验证：输入发起任务、草稿切换、文件保存、两个真实终端、刷新接续、重新登录后的同一任务审批，以及未登录／错误来源和普通成员的拒绝。使用隔离数据及两次预定模拟模型调用，相关编译通过。真实手机软键盘、HTTPS 代理及公网链路仍需具体部署验收，真实用户数据没有改动。

连接管理另外通过真实 HTTP 定向回归，以及隐藏桌面和 Web 页面操作：共享草稿、加密凭据、单设备撤销、保持端口的令牌轮换、停止入口返回应答、SSE 关闭、端口冲突与修复均已验证。停止入口时的排队事件写入已结束响应问题已修复。主动撤销登录会使该页面仍在等待的请求收到 401，这是访问撤销的结果；其余设备继续使用原连接。
