# 独立平台子代理

工作台提供子 agent 面板，主聊天工具卡中的“打开详情”会定位对应运行。面板复用原监视器的运行列表、耗时、调用说明、模型输出、思考内容、工具记录、消息渲染和历史分页。返回文件工作台时保留已打开文件及编辑内容。桌面和 Web 使用同一界面。

## 运行与控制

`subagents` 工具保留原声明参数：`agentName`、`prompt`、`context`、`continueFromRunId` 和 `background`。General Worker 继承派发时的模型选择，其他代理使用已保存配置；子代理工具范围始终取自身配置与派发任务工具集合的交集。

执行仍经过共享核心的账号授权和现有工具审批设置。授权判断是本地代码逻辑，不调用模型、不额外弹出确认。已配置的审批规则与可选操作审核仍按原设置执行。

每个子代理拥有独立对话记录，关联父任务，使用同一文件事务、模型适配器与上下文服务。子对话在监视器查看，不挤入普通主会话列表。并发排队复用原信号量和配置，嵌套深度沿用两层上限。前台父代理等待子代理时释放并发席位，避免多个父代理同时占用席位等待子任务。

暂停会在当前模型请求或工具结束后的边界生效；界面会区分已收到暂停请求和实际暂停。继续恢复当前运行，停止取消对应核心任务。运行失败后是否等待监视器处理，遵守已有失败策略。新平台记录支持从已结束运行中的模型消息重试；消息删除与重试经过版本和消息身份校验，保留修改前快照。

等待中的工具确认和异步问题直接显示在监视器中。通过 Bot 派发的子代理，其问题和确认可以经原 Bot 会话返回，账号归属仍由服务端确定。

## 后台结果

后台调用立即返回独立任务 ID，父任务停止不会取消已启动的后台子代理。可以从后台任务栏或监视器显式停止；删除父对话时停止并清理关联的子对话。

后台结果先保存在服务端队列。主任务运行时在模型边界追加结果，空闲时写入主对话历史；事件通知只负责刷新界面，前端不会再次提交同一份回执。短暂断线或页面关闭不承担结果交付责任。当前空闲回流只追加结果，尚未迁入旧前端自动发起主模型汇总的完整行为。

## 旧运行与当前状态

旧子代理记录继续使用原正文、上下文压缩记录和分页规则。旧宿主的运行句柄不会迁移；未结束记录在新宿主显示为中断。没有独立任务配置的旧运行目前供查看和历史删除，重试按钮按能力隐藏；新平台创建的运行可以继续和重试。

本批依照用户要求未运行测试、类型检查、构建、真实模型请求或子代理执行。源码接入不代表本轮运行验证通过；流式中途取消的未提交增量、旧运行继续与后台自动汇总仍需继续完善。
