# 独立平台技能

技能扫描与 frontmatter 解析复用原 `SkillsManager` 的实现，VS Code 入口只提供工作区变化通知。独立服务按任务捕获的工作区扫描 `.graycode/skills`、`.limcode/skills`、`.agents/skills`；主人还可以使用原用户技能目录和本平台存储目录中的技能。普通授权账号只读取获准工作区内的技能，不扫描主人的全局技能目录。未配置的新技能沿用原来的默认启用行为。

`read_skill` 保留按名称读取正文的用途，增加 `name: ""` 作为当前任务技能目录入口。声明本身保持固定，技能名称与说明通过当前上下文中的 `SKILLS` 条目或目录结果提供；原预设可以继续控制该条目的位置。禁用状态在读取时生效，切换界面工作区不会改变已经启动任务的技能目录。

原技能面板可列出、刷新、启用、禁用和移除丢失的配置项。对话开关更新对应对话的输入配置；全局开关进入统一设置草稿。桌面端可打开技能目录。刷新和模型读取只扫描现有文件，不创建示例技能或修改源目录。

设置导入的技能正文随统一草稿提交，撤销不会提前写入正式记录。旧独立版 `imported-skills` 记录在加载时兼容读取，后续保存使用新版设置事务；导出也包含技能正文。原设置导出格式只包含名称、说明与正文，不包含技能目录中的脚本或其他资源，因此导入的此类技能不会伪造可用的 `basePath`。源目录技能仍返回真实资源目录。

本次没有运行测试、类型检查、构建或真实技能扫描。记忆工具属于后续迁移工作，技能读取接入不代表长期记忆已完成。
