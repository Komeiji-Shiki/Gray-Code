# 独立平台长期记忆

原记忆系统的 wake、note、recall、compress、zoom、forget 和 config 工具已连接独立运行器。`MemoryEngine` 复用原来的分段读取、正则检索、二叉摘要、压缩顺序和字节预算；旧 `MemoryManager` 保留文件宿主，独立应用使用 `DatabaseMemoryStore`，不设置扩展的全局记忆管理器。

记忆内容按账号隔离，并在同一账号内区分全局与工作区。模型不能通过参数选择其他账号；工作区来自当前任务捕获的目标。只读调用不创建记忆目录或数据库条目。记忆仍按需读取，不会因为接入独立版而在每轮请求中自动追加全部内容。

数据库格式升级到版本 4，新增记忆作用域、按位置索引的原始条目、摘要及修订表。正文进入已有压缩去重对象存储。普通追加只写新增条目；删除保持原来的连续编号语义，移动位置时共享已有正文对象。编辑或删除条目时，相关摘要的失效与原始数据更新、修订记录同事务提交。修改来源记录当前运行、对话和工具调用；界面操作单独标注。

原设置页可以列出、新增、编辑和删除原始记忆，支持全局与工作区切换。修改既有条目必须携带列表修订号，旧列表不会在编号变化后继续删除另一条记忆。页面提供撤销最近一次记忆修改；撤销自身也保存为修订。修订引用的正文已纳入对象回收的保留范围，没有自动设置保留期限或清理旧记录。

记忆数值参数和提示词的页面修改进入统一设置草稿，保存时与其他设置一起提交；若模型工具期间改过记忆参数，保存通过修订冲突提醒用户重新加载。模型的 `memory_config` 继续直接修改其账号内共享的记忆格式配置。

旧数据目录的完整导入已接入 `memory/LOG.txt`、`memory/TREE`、共享 `config`，以及 `memory-workspaces` 内的工作区记忆。记录解析支持原 320 字节与现 1024 字节 LOG，摘要沿用 288 字节记录。原始编号、日期、正文与二叉摘要范围分别验证；损坏记录、撕裂尾、归属不一致或读取期间改变的来源会保留为问题，不自动修复源文件。远程工作区 URI 需要显式映射，不能猜成本地路径。

导入先写入与正式账号隔离的暂存作用域，按来源指纹续传；完成后在一次事务中发布条目、摘要、撤销记录及幂等标记。已有正式记忆不会被覆盖，同一来源再次导入会跳过；来源后来发生变化则要求明确合并。当前记忆参数存在时予以保留，若与旧配置不同，报告会把旧配置留作未处理项。仅选择部分对话时不隐式导入共享记忆。空的摘要目录也会被识别，避免误报为未迁移数据。

本阶段没有运行测试、类型检查、构建、数据库升级、真实导入或工具调用，因此导入接通不等同于完成迁移验收。角色陪伴记忆、自动冲突识别和过期内容维护仍属于后续规划。
