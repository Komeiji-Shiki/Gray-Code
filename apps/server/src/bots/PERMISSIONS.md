# Bot 用户权限

在“账号与授权”的“未绑定用户的默认权限”中选择“自定义默认权限”，即可直接设置工作区、操作权限和逐项 MCP 工具。此入口会创建并选中一个非主人权限账号；也可以选择已有账号复用权限。选择和编辑均随“保存全部”生效。

所选账号以 `botGuestAccountId` 保存，未绑定的 Discord / OneBot 用户使用对应账号的权限。空值保持未绑定用户不能主动触发对话。默认访客使用按平台、网络和真实用户 ID 区分的运行身份，共享权限不等于共享运行身份。

`bindings` 可为指定用户选择不同账号，也可通过 `blocked` 拉黑。拉黑、失效绑定和已撤销账号都不会回退到默认权限。删除权限账号时保留关联用户的拉黑记录；配置导入保留本机账号、绑定和默认访客选择。

`mcpTools` 是具体 MCP 工具的允许列表。列表存在时，只有列出的工具可以执行，即使同一账号拥有高风险操作权限，也不会开放其他 MCP 工具。缺省字段用于保留旧账号的权限语义；新建权限账号使用空列表。工具自动执行设置继续决定已经获准的工具是否需要确认。

`botWorkspaceAccess` 默认开启，仅补充当前 Bot 对话专用目录的访问范围。内置文件、终端等操作仍需要各自的操作权限；其他频道的目录和普通项目不会因此获得授权。MCP 工具由对应服务器执行，逐工具允许列表不代替服务器自身的文件访问或网络策略。

每次模型及工具执行会重新核对当前权限与 Bot 回复路线，子任务也沿用来源路线。频道允许列表、触发方式和主人私聊设置继续生效；群聊来源、昵称及引用内容不会授予权限。
